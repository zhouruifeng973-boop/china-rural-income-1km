# v1.5无道路版本县内均一基线与参数敏感性

县内均一基线保持每个县的人口加权平均值不变，仅移除县内像元差异。
它用于说明机器学习表面包含多少县内空间信息，不是像元精度验证。

## 解释边界

这些实验评估县级验证指标和县内空间结构对参数选择的稳健性。
没有乡镇、村庄或住户尺度真实收入时，结果不能解释为1 km像元精度。
