# Public display boundaries

The publication-map scripts expect the 2019 China ADM0 and ADM1 `gbOpen` layers from geoBoundaries at:

```text
geoboundaries_CHN_2019/ADM0/geoBoundaries-CHN-ADM0.shp
geoboundaries_CHN_2019/ADM1/geoBoundaries-CHN-ADM1.shp
```

Download the all-format archives from the geoBoundaries API:

- https://www.geoboundaries.org/api/current/gbOpen/CHN/ADM0/
- https://www.geoboundaries.org/api/current/gbOpen/CHN/ADM1/

The archives and extracted source layers are not redistributed in this repository. They are used only as cartographic context and do not replace the restricted county geometry used for model fitting, aggregation or calibration.

Citation: Runfola, D. et al. *geoBoundaries: A global database of political administrative boundaries*. PLoS ONE 15, e0231866 (2020). https://doi.org/10.1371/journal.pone.0231866.
